# Roundtable — Solano Yards unit-mix workshop (product & floor-plan mix)

A panel-of-equals decision: eight disciplines each get the floor every round,
then the CROSSFIRE half-round lets them attack each other's scheme picks
directly. Three concrete options force a committed choice.

## PROBLEM STATEMENT (paste into the brief)

```
Solano Yards is a fully entitled 3.1-acre multifamily site two blocks from the
Rural Rd light-rail station in Tempe, Arizona (fictional), approved for 280
units in a 5-story wrap. We must lock the unit mix this quarter to start
construction documents. Three schemes are on the table: Scheme A (studio/1BR-
heavy, 296 units), Scheme B (balanced, 280 units), Scheme C (family-leaning
with 2BR/3BR emphasis, 252 units). Which scheme maximizes stabilized NOI and
lease-up speed for a 2028 delivery, and what parking ratio and amenity budget
should accompany it? Pick ONE scheme — hybrids only if a specific unit-count
adjustment is named.
```

## QUESTIONS TO RESOLVE

1. `Which scheme wins on stabilized NOI once realistic $/SF premiums and
   lease-up speed are both counted?`
2. `What rent premium do micro-units and studios really achieve near campus,
   and how durable is student-adjacent demand?`
3. `Is there family/roommate demand for 3BRs at this node, or does Scheme C
   overbuild an unproven segment?`
4. `What parking ratio does this transit location actually need — and what
   does every deleted stall add to yield?`
5. `Which amenity package matches the winning scheme's renter profile without
   gold-plating?`

## SUCCESS CRITERIA (one per Enter)

- ONE scheme named as the recommendation, with any unit-count adjustments specified
- A projected rent roll rationale tied to the comp survey, not hope
- A lease-up forecast in units/month with the evidence behind it
- The parking ratio decision with its cost consequence
- The strongest argument AGAINST the winning scheme, preserved on the record
