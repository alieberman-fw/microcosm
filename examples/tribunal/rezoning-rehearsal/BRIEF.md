# Tribunal — The Larkspur rezoning rehearsal (entitlement)

The two-sided contested question, run as a hearing before the hearing:
advocates argue, opponents rebut, COUNTER volleys fly, and the judge rules
each round. The output is approval odds and the concession package that
changes them.

## PROBLEM STATEMENT (paste into the brief)

```
The Larkspur is a proposed 380-unit apartment community with 14,000 SF of
ground-floor retail on the 9.8-acre Covenant Church surplus parking site at
Milbrook Rd & Leland Ave in north Raleigh, North Carolina (fictional). It
requires a rezoning from R-4 to RX-4 with a height condition. The site is
bordered on two sides by the Ashford Grove single-family neighborhood, which
has organized against the project. City council votes in 90 days. Rehearse the
hearing: will this rezoning pass as filed, what are the odds, and what
specific concession package flips it from contested to approvable? Argue it —
do not average it.
```

## QUESTIONS TO RESOLVE

1. `Does the traffic study survive cross-examination — is the Milbrook/Leland
   intersection the issue that kills the case?`
2. `Which opposition claims are factually right, which are wrong, and does
   correcting the record actually move votes?`
3. `What concession package (height taper, buffer, traffic money, affordable
   set-aside) buys five council votes at the lowest project cost?`
4. `What precedent does approval or denial set for the corridor, and how much
   does that weigh on swing votes?`

## SUCCESS CRITERIA (one per Enter)

- Approval odds as filed AND with the recommended concession package
- A round-by-round scorecard of which arguments actually landed
- The concession package itemized with its cost to the project
- Opposition claims fact-checked against the documents, on the record
- A recommendation: file as-is, amend first, or delay a cycle
